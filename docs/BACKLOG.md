## 季度审计流程

1. 打开「功能使用统计」，按使用次数排序；
2. 使用 < 5 次的非核心功能 → 讨论删减或放回 P3；
3. 结合效率洞察（时长/省时）判断工具整体价值；
4. 更新本文档状态。
